This page is served by nginx, running on Amazon Linux, inside a container.

If you can read this, your Docker image built, your container started, and port forwarding reached it.

FROM amazonlinux:2023base operating system
RUN dnf install -y nginxweb server installed
COPY index.html /usr/share/nginx/html/this page
CMD ["nginx", "-g", "daemon off;"]start command
